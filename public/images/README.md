# Add your graphics

Put an optimized WebP, AVIF, SVG or PNG here, then set `heroImage` in `src/site.config.js` to `/images/your-file.webp`.

The landing page works without a graphic: its conversation and progress UI are real HTML/CSS. No placeholder image or external image dependency is required.

Keep text in the page rather than baking it into screenshots. Add useful alternative text when replacing decorative artwork with meaningful product imagery.
